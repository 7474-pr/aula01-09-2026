# Órbita

Protótipo institucional de uma plataforma para organizar estudos em equipe. O projeto foi criado como página web estática com HTML e CSS.

## Executar localmente

Abra `index.html` em um navegador. Não é necessário instalar dependências.

## Publicar no GitHub Pages

No repositório, acesse **Settings > Pages**, escolha **Deploy from a branch** e
selecione a branch `feat/site-orbita` com a pasta `/ (root)`. O GitHub disponibilizará o endereço publicado nessa mesma página.

Se a branch `feat/site-orbita` não aparecer na lista, primeiro confirme que ela foi enviada para o GitHub com:

```bash
git push origin feat/site-orbita
```

Depois recarregue a página de configurações do Pages. Se a publicação demorar, aguarde alguns minutos e atualize a página do GitHub.

## Observações

- O mural apresenta somente o perfil GitHub `7474-pr`.
- O formulário é demonstrativo e não envia nem armazena dados.
- As imagens são carregadas do Unsplash e do perfil público do GitHub.
