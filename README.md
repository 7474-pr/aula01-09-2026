# Órbita

Protótipo institucional de uma plataforma para organizar estudos em equipe. O projeto foi criado como página web estática com HTML e CSS.

## Executar localmente

Abra `index.html` em um navegador. Não é necessário instalar dependências.

## Publicar no GitHub Pages

No repositório, acesse **Settings > Pages**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`, depois salve. O GitHub disponibilizará o endereço publicado nessa mesma página.

## Observações

- O mural apresenta somente o perfil GitHub `7474-pr`.
- O formulário é demonstrativo e não envia nem armazena dados.
- As imagens são carregadas do Unsplash e do perfil público do GitHub.
